कर्मसाक्षी Windows सफ्टवेयर

संस्करण v1.0.24 (Windows 10 / 11 64-bit)

१००% आधिकारिक एवं Windows Defender द्वारा प्रमाणित

कम्प्युटरमा कर्मसाक्षी चलाउन तलको विकल्प छान्नुहोस्:

⚡ झन्झटमुक्त Windows (.zip) डाउनलोड (~६५ MB) वा Windows Setup (.exe) सिधै डाउनलोड गर्नुहोस् वैकल्पिक Windows Installer (.msi) डाउनलोड गर्नुहोस् (v1.0.24)
.exe डाउनलोड गर्दा चेतावनी आएमा १ सेकेन्डमा हटाउने तरिका:
१. ब्राउजरमा (Edge / Chrome): यदि "isn't commonly downloaded" देखिएमा छेउको ... (तीन थोप्लो) मा क्लिक गर्नुहोस् ➜ Keep रोज्नुहोस् ➜ Show more थिचेर "Keep anyway" (जे भए पनि राख्नुहोस्) छान्नुहोस्।
२. विन्डोजमा (नीलो स्क्रिन आएमा): "Windows protected your PC" विन्डोमा सानो अक्षरमा लेखिएको "More info" (थप जानकारी) मा थिच्नुहोस् र त्यसपछि तल देखिने "Run anyway" (जे भए पनि चलाउनुहोस्) बटन थिच्नुहोस्।
* सुझाव: माथिको "झन्झटमुक्त Windows (.zip)" बटन थिचेर डाउनलोड गर्दा कुनै पनि चेतावनी बिना तुरन्तै डाउनलोड हुन्छ!
